# ZERO ORIPA – テスト版

8機種のオリジナルゲームとポイ活の操作を確認するための静的なデモです。実広告、課金、換金、実物景品、発送、本人確認は一切行いません。ゲーム内コインや発送ポイントに金銭的価値はありません。保存データは各ブラウザ内にのみ保持されます。

## 実行

`docs/` が公開ディレクトリです。GitHub Pagesで使用する場合は Settings → Pages → Deploy from a branch → `main` / `/docs` を選択してください。収益化・本番運用は別環境で、法的確認と広告事業者の承認後に行います。

テストは Node.js 22 以上で `npm test` を実行してください。
